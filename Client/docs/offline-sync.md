# 本地笔记与同步

笔记先在 Android SQLite（`notes.db`）落盘并进入发送队列，成功后清空编辑草稿，立即显示本地详情。网络请求由 WorkManager 在后台执行，界面不等待图片上传。图片原件仍在应用私有文件目录，活动草稿继续使用原子 JSON 文件。

## 数据与顺序

- `notes` 保存列表摘要、完整详情与删除标记；`outbox` 保存创建、编辑和删除快照。
- 笔记与队列在同一个事务中写入。只有服务器确认的操作序号才会移除，发送期间新增的编辑仍保留。
- 新帖子复用草稿 UUIDv7；创建响应丢失后校验已有内容再确认，避免重复创建或误覆盖 ID 冲突。
- 图片上传票据先落盘，重启后先确认已有对象，再决定继续上传或重新申请地址。失败的单张图片可能整张重传，不是字节级断点续传。
- 编辑先覆盖本地正文，后台按队列顺序覆盖云端；不保存展示用的编辑历史。当前不做多设备冲突合并，以服务器最后收到的编辑为准。
- 删除先隐藏本地笔记；后台删除成功后确认该帖之前的任务。旧拉取结果不能覆盖待同步修改或复活删除内容。
- 本地数据按服务器地址隔离；同一服务器修正访问令牌仍使用原队列，不会把原服务器的笔记自动搬到新服务器。

## 联网与缓存

正常任务受系统联网条件约束，临时网络错误使用指数退避；周期任务用于拉取其他设备变化，系统省电可能推迟执行。手动“重试同步”立即尝试 API，不依赖系统对局域网互联网连通性的判断。

远端分页同步成功后才处理远端删除；拉取失败不会清空本地缓存。完整正文逐步缓存，图片下载完成后离线可查看。尚未缓存的远端图片在断网时无法显示。附件缓存暂不自动淘汰。

列表和详情显示待同步或阶段错误；错误区分申请上传地址、上传、图片确认、正文保存等阶段，不显示认证令牌或签名 URL。配置页通过生成的鉴权 API 测量往返耗时，包含服务器处理，不是 ICMP ping；测试超过十秒显示超时。

## 验证

- 六项 Android SQLite 测试覆盖重开读取、操作快照、确认旧操作不吞掉新编辑、服务器隔离、删除边界与缺失摘要恢复。
- 模拟器断网连续保存两条笔记并重启，队列仍存在；重连重试后服务端各生成一条记录。
- 离线拍照保存后重连，服务端生成一条笔记和一张图片；再次离线改文字并重启，文字与照片均保留。同步后仍是一条消息、一张图片。
- 删除同步后服务端返回 404；仅测试创建的临时记录被清理。
- 连接测试显示成功与延迟（一次局域网样本 556ms），错误地址显示十秒超时。
- 编译、单元测试、Lint 与优化构建通过；尚未在实体手机上验证后台调度及电池策略。

在线 ASR 不经过这套离线队列，继续使用现有协议与服务。
