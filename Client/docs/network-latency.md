# 云端链路延迟检查

2026-09-26，从开发机实时发送同一段 5.45 秒合成 PCM 音频，保持同一模型和识别协议。此为单次链路诊断，不是模型质量评测或手机网络保证。

| 路径 | WebSocket 建连 | 上游 ready | 首次文字 | 停止后最终结果 |
| --- | ---: | ---: | ---: | ---: |
| 本地 Hono 中转 | 25ms | 239ms | 469ms | 209ms |
| 云端 Hono 中转 | 689ms | 3186ms | 5187ms | 15266ms |

同期直连云端短请求有明显波动：帖子列表约 0.83–5.39 秒，S3 health 约 2.29–6.03 秒。请求测试单独建连，不能等同于连接复用后的耗时。一次约 1.58MB 的合成 JPEG 签名 PUT 用时 5.54 秒。

Android API/上传现在共享连接池和 TLS 会话；认证拦截器仅存在于 API 客户端，签名 S3 请求不携带业务令牌。连接超时 15 秒、读超时 45 秒、写超时 60 秒，单次调用上限 90 秒。语音客户端复用网络资源，取消只关闭当前录音的 WebSocket。这些调整避免多余建连和过早失败，不保证改善跨境带宽或 ASR 延迟。

新加坡支持 `qwen-audio-3.0-asr-flash-streaming`。2026-09-27 使用用户提供的新加坡业务空间凭据完成生产切换，保留同一模型与协议。完整云端链路切换前后的一组采样：首次出字 3527ms → 2416ms；停止后收尾 718ms → 1069ms。两次音频均为 5.45 秒，最终文本长度均为 26；单次测量显示首字改善，但不能宣称所有延迟指标都改善。上游凭据和回退备份仅存放私有部署配置中。
