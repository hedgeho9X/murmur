# 拍照处理与画质边界

使用 CameraX 默认拍摄模式和默认分辨率选择，不手动调整曝光时间，不通过降低采集规格提速。相机控制器只启用实际使用的照片捕获，关闭闲置图像分析流。

处理链路：点击并给触感反馈 → CameraX 输出 JPEG → 后台读取尺寸并移动原文件 → Coil 提前解码屏幕预览 → 后台保存草稿 → 显示已解码图片。原始 JPEG 不旋转、不重新压缩，EXIF 原样保留；预览按屏幕尺寸解码，不修改原文件。超过服务端上传限制时保留原件并提示，不静默降低画质。相册导入仍使用原有导入逻辑。

采集期间阻止重复点击。日志只记录耗时和尺寸：`jpegMs` 为相机写完 JPEG，`draftReadyMs` 为预览准备及草稿持久化完成，`firstDrawMs` 为解码后的照片首次执行绘制。最后一项接近 UI 可见链路，但不等同于显示面板实际呈现时刻。

本地模拟器一次完整验证为 JPEG 272ms、草稿就绪 345ms、首次绘制 376ms，尺寸 1392×1392。该结果验证链路和计时点，不用于承诺真机速度；恢复默认画质后仍需在相同光线、相同场景下比较真机端到端耗时与清晰度。
