# Android 第一版验收

日期：2026-09-26。

## 自动验证

- Android Debug APK 可构建，最低 API 26，目标 API 36。
- 单元测试覆盖草稿 UUIDv7 在编辑/恢复后保持稳定，以及 partial 替换、final 去重和跨片段拼接。
- Android Lint 0 errors；仍有依赖版本、国际化和构建工具弃用等 warnings。
- 后端 13 项集成测试，独立 Kotlin 客户端契约测试 2 项。
- ASR REST 升级入口、控制帧/事件 DTO、路径常量均来自 Codegen；手写层负责设备和传输生命周期。

## API 35 模拟器

已实际安装并检查：白底圆角取景页、相机权限、CameraX 拍照、拍照后录音/铅笔双按钮、底部编辑弹层与系统键盘、强制关闭后的草稿恢复、设置 API 地址与令牌、创建帖子、读取详情、追加第二条消息、实际上传照片到 S3 并在详情中读取、麦克风权限、静音录音及停止后回到编辑器。

相机图像来自模拟器测试场景，麦克风验证没有真人语音输入；不能作为真机准确率或音质验收。

## 实际 ASR 上游

独立 WAV 经本项目 Hono 转发至 Qwen，8.84 秒中文合成音频，首次文字约 344ms、结束到完成约 297ms；末句完整。此结果仅描述该次请求。

## 当前边界

尚未接入 Hermes 自动回复。生成的消息类型支持工具过程，但当前只写入用户记录。物理设备的权限、照片方向、噪声识别、长录音与公网移动网络仍需验证。当前 App 单份草稿；开启其他记录的补充前若已有草稿，会继续打开原草稿，不自动覆盖。
