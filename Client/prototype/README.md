# Murmur HTML 交互原型

从仓库根目录执行 `python3 -m http.server 8788 --bind 127.0.0.1 --directory Client/prototype`，浏览器打开 http://127.0.0.1:8788 。

- 点击主按钮拍摄演示画面；主动启用相机后可以实际拍照。
- 长按 450 毫秒直接进入模拟录音，松手继续；桌面键盘聚焦主按钮后按 R 也可体验。
- 拍照后左右分别为红色录音与铅笔编辑；录音结束与铅笔共用底部编辑弹层。
- 模拟 ASR 的 partial 替换、定稿拼接及尾部 36 字显示；停顿 1.6 秒后淡出文字，完整文字保留。
- 草稿和记录保存在当前 origin 的 localStorage；发送按钮在原型中标为“保存记录”，不连接业务 API 或 Agent。
- 默认取景为中性占位画面，可点击相机图标启用真实相机，也可选择本地图片。不会上传到服务器。
- 语音是固定文本演示，不请求麦克风或调用付费识别服务；相机权限仅在主动点击时请求。

本目录用于确认交互，不替代 Kotlin Android 实现。编辑器使用真实系统键盘，没有绘制假键盘。

## 本地验收

已在隔离浏览器会话验证：390×844 首屏与编辑弹层、320px 无横向溢出、点按后双按钮、铅笔进入编辑、关闭与刷新后草稿恢复、模拟录音追加文字并进入同一编辑器、本地保存回顾、实际鼠标长按后保持录音且未添加照片。编辑弹层会隔离背景焦点。页面以白底、灰黑图标与绿色编辑操作呈现，不显示宣传语和操作说明；模拟录音保留“模拟”标识，避免误认为已接入真实识别。

真实 Android 键盘、相机权限和触摸长按仍需真机验收；浏览器模拟不等于原生 Android 验证。
